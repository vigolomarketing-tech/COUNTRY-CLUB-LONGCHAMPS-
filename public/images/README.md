# Escudo oficial 3D

Imagen exacta adjunta por el cliente: `1-Foto-1.jpg`, JPEG RGB de 1254 × 1254, con fondo blanco y sin canal alfa. No se recreó, recortó, recoloreó ni filtró. `country-club-logo.png` conserva exactamente los píxeles decodificados del archivo recibido mediante conversión PNG sin pérdida.

Los PNG de 96, 192 y 256 px son reducciones proporcionales para `srcset` del header y footer. Los iconos de 32, 180, 192 y 512 px y `../favicon.ico` muestran la misma imagen, sin textos ni elementos añadidos. El blanco forma parte del adjunto y se conserva. No se eliminó el fondo ni se inventó transparencia.

Los iconos para accesos directos se declaran en `../site.webmanifest`, con rutas relativas compatibles con GitHub Pages. No se agrega service worker ni comportamiento offline.
